# 拾图

拾图是一款面向设计灵感收集场景的 Windows 桌面应用。它用可拖放的桌宠降低收图成本，并把零散图片整理成可搜索、可回顾、可备份的本地灵感资料库。

当前版本：`0.3.22`

## 1. 项目解决什么问题

设计参考图通常散落在下载目录、聊天记录和截图中，时间久了会出现几个问题：

- 收图步骤繁琐，看到灵感时容易先放弃保存。
- 文件名缺少语义，之后很难通过设计语言重新找到图片。
- 图片与当时的思考分离，缺少按时间回顾的入口。
- 云端图库可能带来账号、同步和隐私负担。

拾图采用“本地优先”的方式解决这些问题：用户可以把图片拖给桌面桌宠、拖入图库、从文件选择器导入，或直接粘贴剪贴板中的图片。应用会保存一份本地副本、生成缩略图并记录导入日期；用户也可以选择使用自己的 Gemini API 密钥，为图片生成主分类和 5–10 个中文设计术语。

即使没有网络或没有配置 Gemini API 密钥，本地收集、浏览、搜索、编辑、手账和备份功能仍然可以使用。

## 2. 主要功能

### 快速导入

- 将图片拖到桌面桌宠上。
- 将一个或多个图片文件拖入“全部图片”页面。
- 点击搜索栏旁的 `+`，从文件选择器批量导入。
- 主窗口获得焦点后，按 `Ctrl+V` 粘贴剪贴板中的图片。
- 支持 `JPEG`、`PNG`、`WebP` 和 `BMP`。
- 使用 SHA-256 文件哈希识别重复内容，避免重复入库。
- 应用只复制图片，不会移动或删除用户的源文件。

### 本地图库

- 在“空间”视图中拖动视角、滚轮移动，并手动调整图片位置。
- 切换到“网格”视图快速浏览。
- 按文件名、主分类、设计术语或私人笔记搜索。
- 按主分类、收藏状态和 AI 状态筛选。
- 支持多选后批量修改分类、收藏或移入最近删除。

### 图片详情与相关推荐

- 查看原图、主分类和完整设计术语。
- 添加、删除或复制设计术语，编辑私人笔记。
- 收藏图片、在资源管理器中显示本地副本，或移入最近删除。
- 根据主分类、共同术语、主色、明暗、宽高比和导入时间推荐本地图库中的相关图片。
- 相关推荐只读取本地图库，不会把图库上传到推荐服务。

### 周手账

- 按周和导入日期回顾图片。
- 在日期之间拖动图片，调整手账中的日期归属和卡片布局。
- 查看、复制或删除图片上的设计术语。
- 编写每周笔记，输入框失去焦点时自动保存。

### 可选的 Gemini 分析

- 从预设或用户自建分类中选择一个主分类。
- 为图片生成 5–10 个具体、可搜索的中文设计术语。
- 提供三种模式：`导入后自动分析`、`每次发送前确认`、`关闭 AI，仅本地保存`。
- 支持测试密钥、暂停/继续分析队列、重试失败任务，并对临时网络或限流错误进行延迟重试。
- API 密钥使用 Electron 的 Windows 安全存储能力加密保存在本机，不写入 SQLite 数据库或备份文件。
- 启用 AI 时，仅当前需要分析的图片会发送给 Gemini；图库列表、笔记、相关推荐和备份不会上传。

### 数据管理与个性化

- 新建、重命名、排序、换色或删除主分类；删除分类前会迁移其中图片。
- 从“最近删除”恢复图片，或经二次确认后永久删除。
- 查看图片、缩略图和数据库的本地占用。
- 创建、校验和恢复 ZIP 备份；恢复前会自动备份当前图库。
- 重建全部缩略图。
- 设置桌宠置顶、大小、提示音、音量、显示状态和开机启动。
- 支持跟随系统、日间、夜间主题及减少动画模式。

## 3. 安装方法

### 普通用户

系统要求：

- Windows 10 或 Windows 11，64 位。
- 安装和本地功能不需要 Node.js、Git、Python、数据库或其他运行环境。
- 使用 Gemini 分析时需要网络和用户自己的 Gemini API 密钥。

安装步骤：

1. 从 [GitHub Release v0.3.22](https://github.com/chou71526-rgb/shitu-releases/releases/tag/v0.3.22) 下载 `Shitu-Setup-0.3.22.exe`。当前发布仓库是私有仓库，只有获准访问的 GitHub 账号可以下载。
2. 双击安装包。安装程序会为当前 Windows 用户完成安装并创建“拾图”快捷方式。
3. 安装完成后启动“拾图”。全新安装的图库为空，不包含开发者的图片、API 密钥、缓存或配置。

当前安装包尚未进行数字签名。Windows 首次运行时可能显示 SmartScreen 提示；请先确认文件来自上面的发布页，再点击“更多信息”与“仍要运行”。

当前安装包 SHA-256：

```text
31081A46D6B254141D70ACAACBFD51C68EB77498883144FDB3F406FB9E236075
```

> 升级安装会保留当前 Windows 用户已有的拾图数据。卸载程序默认也不会删除应用数据，请在确认已完成备份后再手动清理。

### 从源码运行

建议使用 Node.js 24.x 和 npm。在项目根目录执行：

```powershell
npm ci
npm run dev
```

常用验证与构建命令：

```powershell
npm run typecheck
npm test
npm run build
npm run package
```

`npm run package` 会在 Windows 上生成 NSIS `.exe` 安装程序，产物位于 `release/`。

## 4. 使用方法

### 第一次使用

1. 启动应用。主图库和桌面桌宠会同时出现。
2. 如果只想本地使用，进入 `数据与设置 → Gemini 与隐私`，选择“关闭 AI，仅本地保存”。
3. 如果需要 AI 分类，在同一页面输入自己的 Gemini API 密钥，点击“安全保存”和“测试连接”，再选择自动分析或发送前确认。
4. 使用以下任一种方式导入图片：拖给桌宠、拖入主图库、点击 `+` 选择文件，或在主窗口按 `Ctrl+V` 粘贴图片。
5. 在“全部图片”中搜索、筛选或整理图片；双击图片进入详情页。
6. 在详情页编辑分类、术语和私人笔记，并浏览本地相关推荐。
7. 在“周手账”中按日期回顾图片并记录当周观察。
8. 定期进入 `数据与设置 → 图库数据` 创建 ZIP 备份。

### 桌宠操作

- 拖动桌宠：移动它在桌面上的位置。
- 将图片拖到桌宠：导入图片并播放接收动画。
- 双击桌宠：打开主图库。
- 右键桌宠：打开图库、隐藏桌宠或完全退出应用。
- 关闭主窗口只会隐藏主窗口；应用和桌宠仍在运行。需要完全结束进程时，请使用桌宠右键菜单中的“退出”。

## 5. 输入输出示例

拾图是桌面图形应用，不是命令行转换工具。这里的“输入”和“输出”表示一次图片导入后在本地图库中产生的结果。

### 示例一：完全本地导入

输入：

```text
文件：poster-reference.png
格式：PNG
方式：拖入主图库
AI 模式：关闭 AI，仅本地保存
```

输出：

```text
- 原图副本写入当前用户的拾图数据目录
- 生成最长边不超过 720 px 的 WebP 缩略图
- “全部图片”中出现 poster-reference.png
- AI 状态显示为“仅本地”
- 图片按导入日期出现在对应周手账中
```

再次导入内容完全相同的文件时，应用会根据文件哈希识别为重复项，不会创建第二份图片。

### 示例二：启用 Gemini 分析

输入：

```text
文件：landing-page-reference.jpg
格式：JPEG
方式：拖给桌宠
AI 模式：导入后自动分析
前提：已保存并测试用户自己的 Gemini API 密钥
```

界面中可能得到类似结果：

```json
{
  "primaryCategory": "网页设计",
  "terms": ["不对称排版", "高饱和撞色", "玻璃拟态", "大标题", "模块网格"]
}
```

实际分类和术语由图片内容及 Gemini 返回结果决定。无论 AI 分析成功、失败或尚未配置密钥，图片都会先保存在本地图库中。

## 数据与隐私说明

- 原图副本、缩略图、SQLite 数据库、分类、术语、笔记、布局和设置保存在当前 Windows 用户的应用数据目录。
- API 密钥单独加密保存，不包含在图库备份中；恢复备份后需要重新配置密钥。
- 应用不要求账号登录，也不使用云数据库同步图库。
- 开启 Gemini 分析会把当前待分析图片的缩放 JPEG 版本发送给 Gemini，因此不能把 AI 模式描述为完全离线。
